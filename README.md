# Portfolio académico — Andrés Roques Sánchez

Portfolio web estático organizado por curso y asignatura, en orden descendente.

## Abrir

Abre `index.html` en cualquier navegador moderno.

## Criterio de selección

El portfolio incluye **trabajos propios con valor demostrable**: proyectos finales, memorias, modelos, presentaciones, dashboards, código, prácticas técnicas y, en los cursos iniciales, ejercicios aplicados que muestran fundamentos relevantes.

Se excluyen temarios, documentación docente, enunciados, soluciones de exámenes/pruebas, lecturas de referencia, dependencias generadas, duplicados y archivos incompletos que no permiten atribuir una implementación propia con claridad.

Cuando una entrega contiene credenciales, información personal o contexto residencial, se publica solo una versión saneada o una síntesis anonimizada.

## Material revisado pero no publicado

### 1º de Máster
- `SSMM`: predominan guiones y trabajos previos, sin una memoria final propia entre los archivos recibidos.
- `VETIC`: teoría, lecturas, casos base y tests; no se identificó una entrega propia suficientemente diferenciada.
- `Practicas.zip`: copia mixta con duplicados de IRAC, ISIN, SCOM y SSMM.

### 4º de Grado
- `RSRD`: soluciones de pruebas/material docente; no se consideran proyectos propios de portfolio.
- Prácticas preparatorias de `ISST`: se prioriza el proyecto final DIY4Rent.
- Laboratorios rutinarios de `CDPS`: se priorizan las prácticas creativas de automatización y cloud.

### 3º de Grado
- `SDG1`: práctica introductoria de C con un único `main.c`; se revisa pero no se publica porque aporta poco valor frente al proyecto Retina de SDG2.
- `CORE`: se revisaron las 10 prácticas. P2/P6 contienen información personal histórica, por lo que se describen sin redistribuir esos datos; P7–P10 se muestran como evolución acumulativa del blog.
- `COPT`: no se publican guiones ni escenarios `.osp` proporcionados por la asignatura; solo resultados propios.
- `ORGE`: no se publica la memoria completa porque contiene fotografías y datos identificativos de otros integrantes; se conserva el modelo financiero y evidencia anonimizada.

### 1º y 2º de Grado
- Se han agrupado prácticas y ejercicios por asignatura para no inflar artificialmente el portfolio con cada hoja individual.
- En `PROG` se publica únicamente el código que existe en los ZIP recibidos; faltan algunas clases de dominio, por lo que el paquete se identifica como selección histórica y no como aplicación ejecutable completa.
